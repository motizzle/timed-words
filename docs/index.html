timed-words

When each word is said or sung in a recording. Press play: each word lights as it is heard. Tap a word to jump to it.

Run it on your own recording

pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install git+https://github.com/motizzle/timed-words
python -m timedwords.song song.mp3                        # a song: its lines, each word timed
python -m timedwords.talk talk.mp3                        # a talk: paragraphs with their start times
python -m timedwords.align reading.mp3 text.txt out.json  # a Hebrew reading whose text you have

The code and how it works: github.com/motizzle/timed-words
